# Portfolio

Personal portfolio of T Saiprashanth. Plain HTML, CSS and JavaScript, no build step.

Live: https://saiprashanth-portfolio-eta.vercel.app

## Run locally

Open `index.html` in a browser.

## Deploy

```
npx vercel deploy --prod --yes
```

## Structure

- `index.html`, `styles.css`, `script.js`: the site
- `certs/`: certificate images shown in the popup
- `icons/`: tech stack logos used by the hero globe
- `Resume.pdf`: linked from the Resume buttons
